What is KoboldCpp?

KoboldCpp is free, open-source software for running compatible AI models on your computer. It builds on llama.cpp and includes KoboldAI Lite, a browser interface for chat, writing, and more. Media generation and API integrations extend it beyond text.

Is it free, and do I need an account?

KoboldCpp itself is free and does not require an account for local generation. Models have separate licenses. Optional hosted services, GPU rentals, and external APIs may require accounts or payment.

Does KoboldCpp work offline?

Yes, once you have downloaded the executable and all required model files, local generation can work offline. Features that contact external services—such as web search or a remote model provider—still need a connection.

Can I use it without a GPU?

Yes. CPU inference is supported. Start with a small, quantized model and a modest context size. A compatible GPU can improve speed through partial or full offload, but available RAM and VRAM still limit what fits.

Why does it ask me to select a model?

The app and the model are separate. Download a supported GGUF text model and select it in the launcher, or load a quick launch template that can fetch its model files. See the model guide and template library.

The model runs out of memory. What should I change?

Lower the context size first, then reduce GPU layers if the error is about VRAM. Close other memory-heavy applications or use a smaller model/quantization. Extra vision, image, and audio models also consume memory. Autofit can help on supported configurations, but it cannot make unlimited models fit.

Why is generation slow?

Check the console to see which backend is actually in use and how many layers were offloaded. A large model on a CPU, partial offload, a long prompt, or memory pressure can reduce speed. Try a smaller model, a shorter context, and a supported GPU backend. The wiki covers deeper tuning.

localhost:5001 will not open. What now?

Keep the KoboldCpp process running and wait until the model finishes loading. Check the terminal for errors and the address/port it reports. The default is port 5001; --port changes it. “localhost” means the device you are currently using, so a phone needs the server computer’s LAN address instead.

Why does it repeat itself or give strange answers?

Confirm that the model loaded correctly and that you chose the right mode and prompt format for it. Start a fresh session with a short prompt and default sampling settings. Consult the model card before changing advanced samplers, chat templates, or context settings. Different models suit different tasks.

Does every GGUF file work?

GGUF is a format, not a guarantee of architecture support. Use a current KoboldCpp build and check the release notes for newly added architectures. A file may also be incomplete, require extra components, or belong to a different task. Read its model card and the console error.

What is the difference between .kcppt and .kcpps?

A .kcppt file is a shareable launch template that can include model download URLs. A .kcpps file saves launcher settings for your setup. Neither is the same as the prompt/chat template that formats messages for a model. See the comparison.

Why does image recognition need an mmproj file?

Supported vision models use a projector to connect image representations with the language model. Use the projector matched to that model family and size. An unrelated projector will not enable vision on an arbitrary text model.

Do I need to install KoboldAI Lite separately?

No. It is bundled with KoboldCpp and normally opens through the local server. The hosted Lite interface is also available, but it needs a supported backend or provider for generation. A web page alone does not load your local GGUF.

Can I connect SillyTavern or another API client?

KoboldCpp provides several compatible API endpoints, including Kobold-style generation and OpenAI-style completions. Select the matching provider type in your client and use the server address and port. OpenAI-compatible clients commonly use a base URL ending in /v1; follow the client’s instructions for exact formatting.

Can I use KoboldCpp from my phone?

You can run the model on your computer and connect from your phone on the same LAN using the computer’s address and port, if the server binding and firewall allow it. Public tunnels and remote access need deliberate access controls. Start with the wiki’s networking guide rather than opening router ports casually.

My operating system warns about the executable. Is that normal?

An unsigned or newly released binary can trigger reputation warnings, but do not treat every warning as a false positive. Check that the download came from github.com/LostRuins/koboldcpp/releases, inspect the release notes and any provided checksums, and ask the project if uncertain.

Is koboldcpp.com an official website?

No. The project README identifies koboldcpp.com as unofficial and warns about impersonation. Use LostRuins/koboldcpp releases on GitHub for official downloads. This community website is koboldcpp.net. See the trusted-source guide.

Still stuck? Bring a little context.

Share your KoboldCpp version, operating system, GPU and RAM/VRAM, model filename, backend, launch settings, and the relevant error message. Remove private paths, API keys, and personal content from logs before posting.
