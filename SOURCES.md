The Discord, Docker, RunPod, SimplePod, conversion-tool, and Colab links come directly from the project README/wiki. They are external services and can redirect, require a login, or change independently. SourceForge is labeled as a mirror; third-party model publishers and cloud services are identified separately from official releases.

Before significant releases, recheck executable names, platform support, model links, template contents and stated memory targets. Avoid treating memory guidance as a guaranteed fit. Keep the template file links so readers can inspect current contents.

The `.com` warning is attributed to the project README. No page links to the lookalike domain. Do not add ratings, invented user counts, unverifiable security endorsements, copied competitor material, or untested performance claims.

Project screenshots and `niko.ico` are copied from the current KoboldCpp checkout. Their upstream source is the LostRuins/koboldcpp repository. The project’s AGPL-3.0 license is included in `LICENSE.md`; upstream attributions are retained here. The social card is a local typographic composition using the existing project icon.
