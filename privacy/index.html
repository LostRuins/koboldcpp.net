Privacy, in plain language.

This website is a static guide and resource directory. You can read it without creating an account.

What this website does

The site code does not include advertising, analytics trackers, third-party fonts, account systems, or contact forms. Search and filtering on resource pages run in your browser without sending the query to a server. The site code does not set cookies or use local storage.

Hosting and access logs

Like any website, the service hosting these pages may receive standard request information, including your IP address, user agent, requested URL, and request time. Hosting-provider logging and retention depend on the deployment configuration.

External links

Following a download, model, community, or cloud-service link takes you to another service. Those sites have their own privacy policies and terms. The copy-command button writes the displayed command to your clipboard only when you click it.

The app and your prompts

This website does not receive prompts or run your AI model. In KoboldCpp, local generation and optional remote features are different workflows. When you connect to a remote provider, use web search, or enable a network service, data handling depends on that feature and provider.
