How to use a .kcppt file

  1. Open a collection above, choose a template, and download the actual .kcppt file from Hugging Face. If it opens as text, use the file’s download button or save the raw file with its original extension.
  2. Open KoboldCpp and load the template through the launcher. Check the models and settings it selects.
  3. Choose the backend for your hardware. Shared templates omit device-specific choices so you can make those locally.
  4. Launch, and allow the referenced model downloads to finish. Internet access and free disk space are needed for this first step.
  5. Open the interface when the server is ready. Use Lite for text, StableUI for images, or MusicUI for music, as appropriate.

For command-line users on Windows, with the template in the current directory:

.\koboldcpp.exe --config example.kcppt

Replace example.kcppt with your downloaded filename. On Linux or macOS, use your platform’s executable name in place of .\koboldcpp.exe.

.kcppt, .kcpps, or prompt template?

TypeWhat it does
.kcpptA shareable quick launch template. Stores configuration and can include model download links; avoids device-specific settings.
.kcppsSaved launcher settings for your setup. Useful for reopening the same model and hardware configuration.
Prompt / chat templateThe format used to arrange system, user, and assistant messages for a model. It is a different concept from a quick launch template.

Use the launcher’s save/export controls to keep configurations you want to reuse. A launch template helps set up a model; it does not automatically make every model suitable for every task.

If a template does not launch

Check the log for a failed download, missing file, unsupported model, or memory error. Confirm that your KoboldCpp build is current enough for the template. Some upstream files require agreeing to a model license or obtaining access first.

If memory is the issue, use fewer components, lower the context, or pick a smaller model. Keep in mind that loading a whole starter pack is more demanding than running one text model.
